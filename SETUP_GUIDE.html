1

📱 إنشاء بوت تلجرام

أ — إنشاء البوت
افتح تلجرام وابحث عن @BotFather ثم أرسل: 
/newbot
اتبع التعليمات وستحصل على توكن مثل: 
1234567890:AAFxxxxxxxxxxxxxxx
ب — معرفة User ID الخاص بك
ابحث عن @userinfobot وأرسل له /start سيُرجع لك رقمك مثل: 123456789
2

▶️ إعداد YouTube API

أ — إنشاء مشروع Google Cloud
  1. اذهب إلى console.cloud.google.com
  2. أنشئ مشروعاً جديداً (New Project)
  3. فعّل YouTube Data API v3 من APIs & Services → Library
ب — إنشاء بيانات OAuth 2.0
  1. APIs & Services → Credentials → Create Credentials
  2. اختر OAuth 2.0 Client IDs
  3. Application type: Desktop app
  4. حمّل ملف client_secrets.json وضعه في مجلد البوت
ج — أضف حسابك كـ Test User
OAuth consent screen → Test users → أضف بريد Google الخاص بقناتك
⚠️ في أول تشغيل سيفتح المتصفح تلقائياً لتسجيل الدخول. بعدها تُحفظ الجلسة في secret1/youtube_token.pickle
3

📸 إعداد انستاغرام

ℹ️ البوت يستخدم مكتبة instagrapi (غير رسمية). تأكد من تفعيل التحقق بخطوتين إن طلبه انستاغرام.
المتطلبات
  • حساب انستاغرام عادي أو Creator/Business
  • يُفضّل استخدام حساب لا يحتوي على 2FA لأول مرة
  • اسم المستخدم وكلمة المرور فقط
⚠️ لا تُفرط في الرفع (أكثر من 10 فيديوهات يومياً) لتجنب الحظر المؤقت.
4

⚙️ إعداد ملف .env

انسخ الملف وعدّل القيم: 
cp .env.example .env
المتغيرالقيمةمن أين؟
TELEGRAM_BOT_TOKEN توكن البوت @BotFather
ALLOWED_USER_ID معرّفك الرقمي @userinfobot
INSTAGRAM_USERNAME اسم المستخدم حسابك
INSTAGRAM_PASSWORD كلمة المرور حسابك
YOUTUBE_CLIENT_SECRETS client_secrets.json Google Cloud
5

🚀 تثبيت وتشغيل البوت

تثبيت المكتبات
cd telegram_video_bot
pip install -r requirements.txt
تشغيل البوت
python main.py
✅ في أول تشغيل سيفتح المتصفح لتسجيل الدخول على يوتيوب. بعدها يعمل البوت بشكل تلقائي.
6

🔄 تشغيل دائم (اختياري)

لتشغيل البوت على سيرفر Linux بشكل دائم:

باستخدام systemd
[Unit]
Description=Telegram Video Bot
After=network.target

[Service]
WorkingDirectory=/path/to/telegram_video_bot
ExecStart=/usr/bin/python3 main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
أو باستخدام screen
screen -S bot
python main.py
