1
إنشاء Snapchat Business Account
A

افتح موقع Snapchat Business

روح على هذا الرابط وسجّل دخول بحساب سناب عادي أو أنشئ حساب جديد

🔗 https://business.snapchat.com
B

أنشئ Business Account

اضغط "Create Account" — ادخل اسم شركتك أو أي اسم (يمكن وهمي) وأكمل البيانات المطلوبة

C

اربط Public Profile

من القائمة الجانبية اختر Snap Publisher ثم تأكد إن بروفايلك عام (Public). إذا ما عندك بروفايل عام، أنشئه من تطبيق سناب مباشرةً.

⚠️ مهم: البروفايل لازم يكون عاماً وعليه منشور واحد على الأقل قبل ربطه بالـ API
الخطوة الثانية
2
إنشاء App والحصول على Client ID و Client Secret
A

افتح Snap Developer Portal

🔗 https://developers.snap.com/my-apps
B

أنشئ App جديد

اضغط + New App ثم:

  • App Name: اكتب أي اسم مثل "MyBot"
  • App Type: اختر Marketing API
  • Redirect URI: اكتب https://localhost:8080/callback
C

انسخ Client ID و Client Secret

بعد الإنشاء ستظهر لك بيانات الـ App. انسخهم واحفظهم فوراً لأن Secret لن يظهر مرة ثانية

# احفظ هذه البيانات في ملف .env
CLIENT_ID = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
CLIENT_SECRET = "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
الخطوة الثالثة
3
الحصول على Access Token عبر OAuth
A

افتح رابط المصادقة في المتصفح

عدّل الرابط التالي بـ Client ID حقتك ثم افتحه في المتصفح:

https://accounts.snapchat.com/accounts/oauth2/auth
  ?client_id=YOUR_CLIENT_ID
  &redirect_uri=https://localhost:8080/callback
  &response_type=code
  &scope=snapchat-marketing-api
B

اقبل الصلاحيات

سيطلب منك تسجيل دخول سناب والموافقة على الصلاحيات. بعد الموافقة سيحولك لرابط مثل:

https://localhost:8080/callback?code=AUTHORIZATION_CODE_HERE
💡 انسخ الـ code من الرابط — ستحتاجه في الخطوة التالية
C

استبدل الـ Code بـ Access Token

شغّل هذا الكود بايثون مرة واحدة للحصول على الـ Token:

import requests

response = requests.post(
  "https://accounts.snapchat.com/accounts/oauth2/token",
  data={
    "grant_type": "authorization_code",
    "code": "AUTHORIZATION_CODE_HERE",  # الكود من الرابط
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_CLIENT_SECRET",
    "redirect_uri": "https://localhost:8080/callback"
  }
)

data = response.json()
print("Access Token:", data["access_token"])
print("Refresh Token:", data["refresh_token"])  # احفظه!
⚠️ احفظ الـ Refresh Token — تحتاجه لتجديد الـ Access Token كل ساعة تلقائياً
الخطوة الرابعة
4
الحصول على Profile ID
A

شغّل هذا الكود

بعد ما حصلت على Access Token، شغّل هذا للحصول على Profile ID:

import requests

ACCESS_TOKEN = "YOUR_ACCESS_TOKEN"

response = requests.get(
  "https://businessapi.snapchat.com/v1/me/public_profiles",
  headers={"Authorization": f"Bearer {ACCESS_TOKEN}"}
)

profiles = response.json()["public_profiles"]
for p in profiles:
  print(f"Profile ID: {p['public_profile']['id']}")
  print(f"Name: {p['public_profile']['profile_name']}")
B

النتيجة

ستحصل على Profile ID يبدو مثل:

Profile ID: 76da494b-76bc-4bbb-bb27-c5a66fb0d1ab
Name: MyChannel
✅ احفظ هذا الـ ID — ستضعه في متغير SNAP_PROFILE_ID في البوت
الملف النهائي
✅
ملف .env النهائي للبوت

بعد ما تكمل الخطوات، ملف الإعدادات يكون هكذا:

# Snapchat API Credentials
SNAP_CLIENT_ID="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
SNAP_CLIENT_SECRET="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
SNAP_ACCESS_TOKEN="eyJhbGciOiJSUzI1NiIsInR5cCI6..."
SNAP_REFRESH_TOKEN="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
SNAP_PROFILE_ID="76da494b-76bc-4bbb-bb27-c5a66fb0d1ab"
🔄 تجديد Token تلقائي: الـ Access Token ينتهي كل ساعة. البوت يجدده تلقائياً باستخدام Refresh Token — الكود جاهز في الملف السابق بدالة refresh_access_token()
